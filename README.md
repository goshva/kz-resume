# kz-resume

Профиль универсального IT-исполнителя (full-stack разработка, боты, мобильные приложения, DevOps) — для фриланс-площадок и первых заказов.

## Просмотр

Открыть `index.html` в браузере, либо включить GitHub Pages в настройках репозитория (Settings → Pages → Deploy from branch → `main` / `root`) — страница станет доступна по адресу вида `https://goshva.github.io/kz-resume/`.
